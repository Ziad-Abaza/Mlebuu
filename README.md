
# Mlebuu

![Mlebuu Logo](https://github.com/Ziad-Abaza/Mlebuu/blob/main/images/Mlebuu.jpeg)

**Mlebuu** is a versatile online meeting application designed to enhance virtual communication for users across different platforms. Available on both Android and PC, Mlebuu offers a robust set of features aimed at facilitating seamless interactions, making it suitable for professionals, educators, and anyone looking to streamline their workflow.

### Features

- **Online Meetings**: Host seamless video calls for individuals and groups, enabling effective communication regardless of location.
- **Chat Functionality**: Engage in real-time text conversations while on a call to enhance collaboration.
- **Screen Sharing**: Share your screen effortlessly during meetings for presentations or demonstrations, ensuring clarity and understanding.
- **Translation**: Communicate in multiple languages, breaking down language barriers and promoting inclusivity.
- **Unlimited Rooms**: Create and manage an unlimited number of meeting rooms, accommodating various discussions and projects simultaneously.
- **User-Friendly Interface**: The intuitive design ensures easy navigation, making it accessible for users of all technical levels.

### Installation Requirements

To run the Mlebuu application locally, you need to have the following:

- A web browser (e.g., Chrome, Firefox, Edge) for accessing the web application.
- A local development environment set up if you wish to modify or test the application features.

### Installation Steps

To get started with Mlebuu, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Ziad-Abaza/Mlebuu.git
   ```
   
2. **Navigate to the Project Directory**:
   ```bash
   cd Mlebuu
   ```

3. **Open the `index.html` file** in your web browser to view and interact with the application.

### Technologies Used

Mlebuu is built using a combination of web technologies, including:

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling and designing the layout to ensure a visually appealing user interface.
- **JavaScript**: To implement dynamic features and interactivity, such as real-time chat and video calling functionalities.

### Important Pages

Mlebuu consists of various important pages that enhance user experience:

- **Home Page**: The main entry point featuring navigation links to all essential sections of the application.
- **Call Page**: Dedicated to video calling, allowing users to initiate and manage calls.
- **About Us Page**: Provides information about the Mlebuu team and mission.
- **Download Page**: Instructions for downloading the app on mobile devices.
- **Contact Us Page**: A form for users to reach out with inquiries or feedback.
- **Events and Workshops**: Lists upcoming events and workshops hosted through Mlebuu.
- **Partners Page**: Displays collaborations and partnerships that Mlebuu has established.
- **Articles Page**: A collection of articles related to online meetings and productivity tips.
