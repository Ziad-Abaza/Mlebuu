
# Mlebuu

![Mlebuu Logo](https://github.com/Ziad-Abaza/Mlebuu/blob/main/images/Mlebuu.jpeg)

Mlebuu is an online meeting application designed to facilitate virtual communication for everyone. Available on both Android and PC, Mlebuu offers various features such as chat, video calls, translation, unlimited rooms, screen sharing, and more. It is suitable for all professionals and aims to streamline workflows.

## Features

- **Online Meetings**: Seamless video calling for individuals and groups.
- **Chat Functionality**: Communicate via text while in a meeting.
- **Screen Sharing**: Share your screen for presentations or demonstrations.
- **Translation**: Communicate in multiple languages effortlessly.
- **Unlimited Rooms**: Create as many meeting rooms as needed.
- **User-Friendly Interface**: Designed for easy navigation.

## Installation

To run the Mlebuu application locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ziad-Abaza/Mlebuu.git
   ```
   
2. **Navigate to the project directory**:
   ```bash
   cd Mlebuu
   ```

3. **Open the `index.html` file** in your web browser to view the application.
